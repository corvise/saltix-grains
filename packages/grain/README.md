# @saltix/grain

The bridge between a mini-app (a *grain*) and the Saltix wallet it runs in: the page's side of Saltix 12-grains §5 — sign-in, payments, the chat and the console, through the wallet's bridge.

```sh
npm install @saltix/grain
```

Part of [saltix-grains](https://github.com/corvise/saltix-grains), the SDK of Saltix mini-apps, MIT licensed. Start with
[the protocol page](https://github.com/corvise/saltix-grains/blob/main/docs/protocol/grains.md) and [Your first app in ten minutes](https://github.com/corvise/saltix-grains/blob/main/docs/first-app.md); the repository's
[README](https://github.com/corvise/saltix-grains#readme) has the whole command line and the protocol pages.
