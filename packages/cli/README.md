# @saltix/grain-cli

The `grain` command line: make, serve, check, sign, register, publish and retire grains, from a project on your computer into the Saltix network — written so that a coding agent can do it alone.

```sh
npm install --save-dev @saltix/grain-cli   # then: npx grain init my-app
```

Part of [saltix-grains](https://github.com/corvise/saltix-grains), the SDK of Saltix mini-apps, MIT licensed. Start with
[Your first app in ten minutes](https://github.com/corvise/saltix-grains/blob/main/docs/first-app.md) and [the agents' guide](https://github.com/corvise/saltix-grains/blob/main/docs/agents/app.md); the repository's
[README](https://github.com/corvise/saltix-grains#readme) has the whole command line and the protocol pages.
