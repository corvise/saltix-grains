# @saltix/grain-server

A grain's server side: sign-in checks, invoices and payments on chain, manifests, Connect profiles, chats — and the network's relays found when it runs, never from a list it carries (41-transport §18).

```sh
npm install @saltix/grain-server
```

Part of [saltix-grains](https://github.com/corvise/saltix-grains), the SDK of Saltix mini-apps, MIT licensed. Start with
[How it works](https://github.com/corvise/saltix-grains/blob/main/docs/how-it-works.md) and [the chat guide](https://github.com/corvise/saltix-grains/blob/main/docs/chats.md); the repository's
[README](https://github.com/corvise/saltix-grains#readme) has the whole command line and the protocol pages.
