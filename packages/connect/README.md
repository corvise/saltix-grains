# @saltix/connect

Sign in with Saltix on a website or DApp: the page's side of Saltix Connect (its button and dialog) and the server's side for a session the server holds (19-connect).

```sh
npm install @saltix/connect
```

Part of [saltix-grains](https://github.com/corvise/saltix-grains), the SDK of Saltix mini-apps, MIT licensed. Start with
[Sign in with Saltix](https://github.com/corvise/saltix-grains/blob/main/docs/connect.md) and [the protocol page](https://github.com/corvise/saltix-grains/blob/main/docs/protocol/connect.md); the repository's
[README](https://github.com/corvise/saltix-grains#readme) has the whole command line and the protocol pages.
